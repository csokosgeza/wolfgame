# WolfGame Project

## Projekt célja

Ez a projekt egy játékfejlesztési kísérlet, amelyben egy AI agent fejleszt egy játékot MCP (Model Context Protocol) segítségével. A cél annak megfigyelése, hogy milyen képességekkel rendelkezik az agent a játékfejlesztés terén.

## Az agent feladatai

1. **Játék típusának kiválasztása**: Az agent szabadon kiválaszthatja a játék típusát (pl. böngésző alapú, terminál játék, stb.)
2. **Technológiai stack kiválasztása**: Az agent dönt a használandó technológiákról
3. **Játék megtervezése**: Egyszerű játékterv készítése
4. **Implementáció**: A játék kódjának megírása
5. **Tesztelés**: A játék működésének ellenőrzése
6. **Dokumentáció**: Rövid leírás készítése a játékról és a fejlesztési folyamatról
