# Assets Mappa

Ez a mappa a játék grafikus és egyéb erőforrásait tartalmazza.

## Mappa szerkezete

```
assets/
├── images/           # Képek (PNG, JPG, SVG)
├── sounds/           # Hangfájlok (MP3, WAV, OGG)
├── fonts/            # Betűtípusok
└── data/             # Adatfájlok (JSON, XML)
```

## Javasolt formátumok

### Képek
- **PNG**: Átlátszó háttérrel rendelkező képekhez
- **JPG**: Fotókhoz vagy komplex képekhez
- **SVG**: Vektoros grafikákhoz, ikonokhoz

### Hangok
- **MP3**: Zenei effektekhez
- **WAV**: Rövid hangeffektekhez
- **OGG**: Alternatív hangformátum

### Betűtípusok
- **WOFF/WOFF2**: Webes betűtípusokhoz
- **TTF**: Asztali alkalmazásokhoz

### Adatfájlok
- **JSON**: Játékadatokhoz, konfigurációhoz
- **XML**: Komplex adatszerkezetekhez
