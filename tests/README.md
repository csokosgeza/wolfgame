# Tesztek Mappa

Ez a mappa a játék tesztjeit tartalmazza.

## Teszt típusok

### Egységtesztek (Unit Tests)
- Egyedi funkciók tesztelése
- Játéklogika komponenseinek ellenőrzése

### Integrációs tesztek
- Komponensek együttműködésének tesztelése
- Adatáramlás ellenőrzése

### Felhasználói felület tesztek
- UI elemek működésének ellenőrzése
- Felhasználói interakciók tesztelése

### Teljesítménytesztek
- Játék sebességének mérése
- Memóriahasználat ellenőrzése

## Teszt keretrendszerek

### JavaScript
- **Jest**: Egységtesztekhez
- **Cypress**: E2E tesztekhez
- **Mocha**: Aszinkron tesztekhez

### Eszközök
- **Lighthouse**: Teljesítményteszteléshez
- **Chrome DevTools**: Debuggoláshoz és profilozáshoz

## Tesztelési folyamat

1. **Tesztek írása**: A fejlesztés előtt vagy közben
2. **Tesztek futtatása**: Automatizáltan minden commit előtt
3. **Eredmények elemzése**: Hibák azonosítása és javítása
4. **Refaktorálás**: Kód minőségének javítása

## Javasolt gyakorlatok

- Írj teszteket minden új funkcióhoz
- Használj leíró neveket a teszteknek
- Tesztelj határeseteket is
- Tartsd a teszteket naprakészen
